# Tellybox for Home Assistant

A Home Assistant integration for [Tellybox](https://github.com/sandermvanvliet/Tellybox): see what's on the TV and how much time each kid has left, and give extra time, unlimited today or a block, from dashboards, automations and phone notifications.

Work in progress (Phase 1, v0.1.0); see `docs/plan.md`. The full README with install steps, entities, actions and safety notes follows with the first release.
